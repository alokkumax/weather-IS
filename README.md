# Weather Forecast Dashboard 🌦️

**Repo Link:** [https://github.com/alokkumax/weather-IS](https://github.com/alokkumax/weather-IS)
**Live Link:** https://weather-is-beta.vercel.app/

Hey! This is a simple weather app I built using HTML, CSS (Tailwind), and JavaScript for IS-FSD. It's a clean dashboard that lets you check the weather anywhere in the world and also see a 5-day forecast.

## What it can do:

- **Search any city**: Just type a name and hit Enter.
- **Find me**: Use the location button to see the weather right where you are.
- **History**: It remembers your last 5 searches so you don't have to keep typing them.
- **Toggle Temp**: You can switch between Celsius and Fahrenheit if you want.
- **Changing Themes**: The background changes colors depending on if it's sunny, rainy, or cloudy!
- **Heat Warning**: If it's super hot (over 40°C), a little warning pops up.

## How to run it:

It's super easy:
1. Just download the files.
2. Open `index.html` in your browser.
3. That's it!

## Tools I used:

- **Tailwind CSS**: For all the styling and making it look modern.
- **Vanilla JavaScript**: To handle the API and all the logic.
- **WeatherAPI**: This is where I'm getting all the actual weather data from.

## Some things to know:

- The app is fully responsive, so it looks good on my phone and my laptop.
- I used a `try-catch` block for errors, so if you type a city name wrong, it just tells you to check the spelling instead of crashing.
- I've added a lot of comments in the code to explain what I'm doing in each part!

Hope you like it!
